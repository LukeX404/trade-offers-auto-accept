# Steam Trade Auto-Accept 🤝

🤝 Auto-accepts Steam trades that are empty on your side.

## Requirements

* 💵 Steam account unlocked ($5 minimum)
* 🛡️ Steam Guard enabled

## Configuration

Create a `.env` file:

```env
STEAM_USERNAME=
STEAM_PASSWORD=
STEAM_SHARED_SECRET=
IDENTITY_SECRET=
STEAM_API_KEY=
```
